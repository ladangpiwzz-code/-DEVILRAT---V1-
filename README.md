## Deployment on Koyeb

### One-Click Deploy
[![Deploy to Koyeb](https://www.koyeb.com/static/images/deploy/button.svg)](https://app.koyeb.com/deploy?type=git&repository=yourusername/devilrat-koyeb)

### Manual Deployment
1. **Push code to GitHub**
2. **Open [Koyeb Dashboard](https://app.koyeb.com)**
3. **Create Service → GitHub**
4. **Select your repository**
5. **Koyeb auto-detects Dockerfile**
6. **Deploy and get your domain**
